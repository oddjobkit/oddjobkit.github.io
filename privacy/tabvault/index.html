Privacy / Tabvault

Restore tabs: session saver & crash backup

Effective
13 November 2026
Applies to
Version 1.0.0
Listing
On the tools page

Saves your open tabs as sessions (automatically and when you ask) and restores them later.

What it can access

  • tabs

    Reads the address, title, pinned state, tab group, position and window size of each open tab, because that is what a saved session is made of. Restore Tabs has no site access and no scripts, so it never reads page content, forms or cookies.

  • storage

    Keeps your sessions and settings on this device, and a short-lived note of which tabs belong to which window while the browser is open. Also reads the optional settings an administrator can set.

  • unlimitedStorage

    Lets people with hundreds of tabs keep many snapshots without hitting Chrome's 10 MB extension limit.

  • alarms

    Takes a safety snapshot every 5 minutes, finishes a snapshot that was waiting for tabs to stop changing if the browser stops the background worker first, checks 45 seconds after the browser starts whether your last session is missing tabs, and reminds you to back up.

  • favicon

    Shows each saved tab's icon from the browser's own cache, so a session is recognisable at a glance. Nothing is fetched: the icons come from the browser's local cache through the extension's own /_favicon/ address. Alongside tabs it adds no install warning.

  • tabGroupsOptional

    Saves and restores your tab group names and colours. Asked for only if you switch it on.

What leaves your device

Nothing leaves your device.

Tab titles and addresses stay on this device. They are handled on this device only; never transmitted, sold or used for anything but saving and restoring your sessions. A file is made only when you press Export.

What is stored

Your sessions live in this browser's extension storage on this computer, plus one copy in an IndexedDB database of the same browser profile that is used to repair the first if it is ever emptied. Files are created only when you press Export.

One honest limit: removing the extension deletes its data. Keep a backup file; Restore Tabs reminds you.

More detail

Restore Tabs does not read your pages, and it has no network code.

It reads these details about each tab: address, title, pinned state, tab group, position in the window and window size. That is what a saved session is. It never reads page content. To show a site's icon it asks the browser's own icon cache (the favicon permission); nothing is fetched.

It has no site access, no page scripts and no content scripts, so it cannot read page text, forms, cookies or passwords.

Its security policy forbids network connections and embedded frames from its own pages and background worker (connect-src 'none', frame-src 'none'), and the source contains no network code. There is no account, no analytics, no remote code and no hidden page.

It is switched off in Incognito and never sees those tabs.

The backup file is plain JSON: { "format": "tabvault-sessions", "version": 1, "exportedAt": ..., "sessions": [...] }, documented in the README.

Check it yourself: chrome://extensions, Details, Permissions; open the manager page, DevTools, Network (empty); read the source and rebuild it from github.com/oddjobkit/tabvault.
