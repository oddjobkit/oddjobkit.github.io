One odd job.
Done properly.

Small Chrome extensions for the job you would otherwise hunt for a sketchy website to do. Nothing is sold.

First release

  • Hexpick

    Pick two colors from your screen or an image to check WCAG 2.2 contrast.

  • Picktext

    Copy text from any screenshot or image.

  • Tabvault

    Never lose your tabs: automatic snapshots, named sessions and JSON backup.

In progress

  • Cookiemute

    Clicks Reject on cookie banners for you and shows what it did.

  • Clipstack

    Search what you copied.

  • Convertsafe

    Convert HEIC, WebP and AVIF to JPG, PNG or WebP on your device.

  • Cleanjson

    Formats JSON as a searchable tree.

  • Localshot

    Strip GPS location, camera details and hidden metadata from JPG, PNG and WebP photos.

  • Captionlocal

    Edit, re-time, split and merge SRT and VTT subtitles beside your video.

How every tool is built

  • No analytics

    No tracking and no telemetry in any extension. Anything that does use the network is disclosed on the listing and in the privacy policy.

  • Few permissions

    Each tool asks for the smallest set that does its job, and every permission is explained in plain words.

  • Source at release

    The source of each tool goes public on GitHub when the tool ships, so the claims can be checked.

  • A person reads the mail

    Store reviews get a reply within a week. Questions go to oddjobkit@gmail.com.
