Oddjob Kit

Small Chrome extensions that each do one odd job well.

The kind of task you'd otherwise hunt for a sketchy website to do, built as a tidy extension that does that one thing and gets out of the way.

How every tool works

  • One job eachNo suites, no feature creep. If it does two things, it's two tools.
  • No accountInstall it and use it. Nothing to sign up for.
  • Honest about dataEach store listing says exactly what the tool touches, and asks for the fewest permissions it can.
