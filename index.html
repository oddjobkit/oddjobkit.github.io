How we build

  • No analytics inside extensions

    No tracking and no telemetry in any extension. Anything that does use the network is disclosed on the listing and in the privacy policy.

  • Minimal permissions

    Each tool asks for the smallest set that does its job, and every permission is explained in plain words.

  • Open source at release

    The source of each tool goes public on GitHub when the tool ships, so the claims can be checked.

  • Replies to reviews

    Store reviews get a reply within a week, and the support address is read by a person.
